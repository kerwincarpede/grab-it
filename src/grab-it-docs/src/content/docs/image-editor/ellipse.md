**Key: `E`**

Drag a box and the ellipse fills it, from corner to opposite corner. Hold **`Shift`** for a perfect circle.

![An ellipse around a number.](../../../assets/image-editor/ellipse.png)

**Options:** colour, a width from 1 to 24 pixels, and **Fill**, which fills it with its colour, see-through so what's underneath still shows. See [Colours and sizes](/grab-it/image-editor/styles/).
