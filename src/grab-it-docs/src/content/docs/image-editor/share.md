The right of the top bar has everything for getting your work out of the editor. Each one uses the finished image: your annotations, crop, turn, backdrop and size, all applied.

| Button | Key | What it does |
| --- | --- | --- |
| **Pin** | | Floats the finished image above your other windows |
| **Copy** | `Ctrl/⌘ + C` | Copies the finished image, as a PNG |
| | `Ctrl/⌘ + Enter` | Copies and closes the editor in one go |
| **Copy text** | | Copies the text in the screenshot (shown once the [Library](/grab-it/library/) has read it) |
| **Export…** | | Saves the finished image as a file |

The status bar confirms each one, for example *"Copied to the clipboard."*

## Export

The image editor, Library and guide share the last folder you chose for export. The first time, the dialog opens in your Grab-it save folder.

**Export…** asks where to save, suggesting the capture's own name followed by `annotated`, such as `Grab-it 2026-11-15 14-05-09 annotated.png`.

Pick a format in the dialog, or end the file name with its ending:

| Format | Ending | Good for | Transparency |
| --- | --- | --- | --- |
| **PNG** | `.png` | Sharp text and screenshots | Kept |
| **JPEG** | `.jpg` or `.jpeg` | Smaller files | White |
| **WebP** | `.webp` | Web pages; saved without any loss | Kept |
| **GIF** | `.gif` | Older tools; at most 256 colours | White |
| **TIFF** | `.tif` or `.tiff` | Printing and scanning workflows | Kept |
| **BMP** | `.bmp` | Older Windows tools | White |
| **PDF** | `.pdf` | Forms and printing: one page the size of the image | White |

Where a format has no transparency, see-through parts come out white. A name without one of these endings is saved as PNG.

## Pin

**Pin** floats the finished image on top of your other windows, as a reference while you work. See [Pin](/grab-it/capture/more-tricks/) for moving, resizing, fading and locking it.

## Copy text

**Copy text** copies the text Grab-it read from the screenshot, so you can paste it as words. It's the text of the original screenshot: cropping or blurring doesn't change it. To copy the text of just a part of the screen, use [Capture text](/grab-it/capture/text-and-codes/) instead.
