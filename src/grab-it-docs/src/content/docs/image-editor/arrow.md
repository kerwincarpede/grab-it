**Key: `A`** · also `Alt/⌥`-drag with any tool

Drag from where the arrow starts to where it points. The arrowhead goes at the end you let go of.

![An arrow pointing from a chart bar to a button.](../../../assets/image-editor/arrow.png)

- Hold **`Shift`** while you drag to keep the arrow at 45° steps: perfectly level, upright or diagonal.
- A drag of only a pixel or two is treated as a stray click, and draws nothing.

## Adjust the handles

A selected arrow has three handles:

- **The middle handle** bends the arrow into a smooth curve. Drag it back close to the straight line and it snaps straight again. On an **Elbow**, it slides the middle segment while both ends stay put.
- **The end handles** move each end. A curved arrow stretches along with it. Hold `Shift` to keep the end at 45° steps from the other one.

## Options

| Option | Where |
| --- | --- |
| Colour | Top bar swatches, or `1`–`7` |
| Style | **Style** beside **Width** |
| Width | **Width** in the top bar, `[` and `]`, or `Alt/⌥ + scroll`: 1 to 24 pixels, 4 to start with |

The arrow keeps its own width: changing it doesn't change your line or rectangle width. See [Colours and sizes](/grab-it/image-editor/styles/).

## Pick a style

Open **Style** to preview the twelve presets. Pick a style with an arrow selected to change that arrow in one undoable edit. With the **Arrow** tool active and no arrow selected, the style applies to new arrows in this editor session, including those drawn with `Alt/⌥`-drag.

| Group | Style | Shape |
| --- | --- | --- |
| Pointers | **Classic** | Thin shaft with a filled triangular tip |
| Pointers | **Open** | Thin shaft with an open chevron |
| Pointers | **Needle** | Fine shaft with a long, narrow tip |
| Pointers | **Dot tail** | Filled dot at the start and a triangular tip |
| Emphasis | **Block** | Broad shaft and a large tip |
| Emphasis | **Outline** | Hollow block that leaves the capture visible inside |
| Emphasis | **Tapered** | Shaft that widens towards the tip |
| Emphasis | **Dashed** | Broken shaft with a filled tip |
| Ranges and flow | **Double-ended** | Filled tips at both ends |
| Ranges and flow | **Capped** | Perpendicular start cap and a filled tip |
| Ranges and flow | **Elbow** | Right-angle connector with a movable middle segment |
| Ranges and flow | **Chevron trail** | Two open chevrons at the leading end |
