**Key: `S`**

Drag a box around what matters. Everything **outside** it is dimmed, so the eye goes straight to it. Hold **`Shift`** for a square.

- Add as many spotlights as you like: everything outside all of them is dimmed, and where they overlap the shade never doubles up.
- Only the screenshot is dimmed. Arrows, text and badges stay bright, even outside the spotlight.
- Spotlight has no colour or width. Move and resize it like any shape.
