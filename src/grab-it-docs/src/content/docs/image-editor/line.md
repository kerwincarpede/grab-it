**Key: `L`**

Drag from one end of the line to the other. Line works just like [Arrow](/grab-it/image-editor/arrow/), without the arrowhead:

![A line underlining a heading.](../../../assets/image-editor/line.png)

- Hold **`Shift`** to keep it at 45° steps.
- Select it to get its handles: drag the **middle** one to curve it (drag it back to straighten it), or an **end** to move that end (with `Shift` for 45° steps).

**Options:** colour, and a width from 1 to 24 pixels. See [Colours and sizes](/grab-it/image-editor/styles/).
