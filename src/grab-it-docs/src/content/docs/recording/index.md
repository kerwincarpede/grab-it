Grab-it records a region, a window or a whole display as an MP4 or an animated GIF, with optional microphone, system sound, webcam, clicks and keystrokes.

- [Record your screen](/grab-it/recording/record/): set up, start, pause and stop a recording.

Recordings are saved to the `recordings` folder inside your save folder. To trim and polish one afterwards, see the [Video editor](/grab-it/video-editor/).
