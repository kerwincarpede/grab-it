| Action | Windows & Linux | macOS |
| --- | --- | --- |
| Capture a region (or click a window) | `PrintScreen` | `⌘ ⇧ 2` |
| Capture a window | `Alt + PrintScreen` | `⌘ ⇧ W` |
| Capture every monitor | `Ctrl + PrintScreen` | `⌘ ⇧ F` |
| Capture text | `Shift + PrintScreen` | `⌘ ⇧ 1` |
| Pick a colour | `Ctrl + Shift + PrintScreen` | `⌘ ⇧ 9` |
| All-in-one: pick any mode from a toolbar | `Ctrl + Alt + PrintScreen` | `⌘ ⇧ A` |

Don't like these? Change them in [Settings](/grab-it/reference/settings/): click a shortcut and press the keys you want. If another app already uses a shortcut, Settings tells you, and the tray menu always works.

**Shortcuts and tips** in the Grab-it window's sidebar shows your current shortcuts at any time.

The editor has its own keys; see [Mark it up](/grab-it/image-editor/mark-it-up/).
