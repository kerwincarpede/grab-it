Grab-it sits in your system tray (menu bar on macOS) and captures with one key. Every screenshot is copied to your clipboard, saved as a PNG in your Grab-it folder (`Pictures/Grab-it` unless you change it in [Settings](/grab-it/reference/settings/)), and shown on a Quick Access card.

| Capture | Windows & Linux | macOS | Page |
| --- | --- | --- | --- |
| A region, or click a window | `PrintScreen` | `⌘ ⇧ 2` | [Region](/grab-it/capture/region/) |
| A window | `Alt + PrintScreen` | `⌘ ⇧ W` | [Window](/grab-it/capture/window/) |
| Every monitor | `Ctrl + PrintScreen` | `⌘ ⇧ F` | [Screen and monitor](/grab-it/capture/screen/) |
| One monitor | tray: **Monitor** | tray: **Monitor** | [Screen and monitor](/grab-it/capture/screen/) |
| After a few seconds | tray: **Timed capture** | tray: **Timed capture** | [Timed capture](/grab-it/capture/timed/) |
| The same region again | tray: **Repeat last region** | tray: **Repeat last region** | [Repeat last region](/grab-it/capture/repeat/) |
| Text, QR codes and barcodes | `Shift + PrintScreen` | `⌘ ⇧ 1` | [Text and codes](/grab-it/capture/text-and-codes/) |
| A colour | `Ctrl + Shift + PrintScreen` | `⌘ ⇧ 9` | [Pick a colour](/grab-it/capture/colour/) |
| Any of the above from a toolbar | `Ctrl + Alt + PrintScreen` | `⌘ ⇧ A` | [All-in-one](/grab-it/capture/all-in-one/) |

New here? Start with [Your first capture](/grab-it/capture/first-capture/), then see [More tricks](/grab-it/capture/more-tricks/) for the tray menu and pins. On a Linux desktop running Wayland, read [Wayland](/grab-it/capture/wayland/) too: a few things work differently there.

To record video instead, see [Recording](/grab-it/recording/).
