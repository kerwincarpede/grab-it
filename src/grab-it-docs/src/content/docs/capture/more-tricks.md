Click the Grab-it icon in the menu bar or tray for every capture. On Windows and macOS the click opens a small panel with a button for each capture, your latest captures, and links to the Grab-it window and Settings; right-click for the full menu. On Linux the click opens the menu.

## The tray menu

| Item | What it does |
| --- | --- |
| **All-in-one** | Every mode from one toolbar; see [All-in-one](/grab-it/capture/all-in-one/) |
| **Capture region** | Drag a region or click a window; see [Region](/grab-it/capture/region/) |
| **Capture window** | Click a window; see [Window](/grab-it/capture/window/) |
| **Capture screen (all monitors)** | Every monitor in one image; see [Screen and monitor](/grab-it/capture/screen/) |
| **Monitor** | One monitor, picked from a list |
| **Timed capture** | A region after 3, 5 or 10 seconds, or the screen after 5; see [Timed capture](/grab-it/capture/timed/) |
| **Repeat last region** | The area you dragged last, again; see [Repeat last region](/grab-it/capture/repeat/) |
| **Capture text** | Copies the text, or a QR code or barcode; see [Text and codes](/grab-it/capture/text-and-codes/) |
| **Pick a colour** | Copies a pixel's colour; see [Pick a colour](/grab-it/capture/colour/) |
| **Record** | Records a video or GIF; see [Recording](/grab-it/recording/) |
| **Unlock pinned captures** | Makes locked pins clickable again (see below) |
| **Show last capture** | Brings the Quick Access card back |
| **Open Grab-it…** | Opens the [Library](/grab-it/library/) |
| **Settings…**, **Shortcuts and tips…**, **Check for updates…**, **Quit Grab-it** | What they say |

## 📌 Pin

Float a capture above everything else as a reference while you work. Pin it from the Quick Access card, the [editor](/grab-it/image-editor/share/) or the Library.

- **Drag** it anywhere.
- **Scroll**, or press `+` and `-`, to make it larger or smaller.
- **`Ctrl/⌘ + scroll`**, or the slider in its toolbar, fades it.
- **Arrow keys** move it (hold `Shift` for bigger steps).
- **`Ctrl/⌘ + C`** or **Copy** copies it, and **Annotate** opens it in the editor (for a saved capture).
- **Lock** lets clicks pass through it to the window underneath. **Unlock pinned captures** in the tray menu makes it clickable again.
- **Double-click**, ✕ or `Esc` closes it.
