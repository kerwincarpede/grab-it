---
title: Repeat last region
description: Capture the exact area you dragged last time again, without dragging.
sidebar:
  order: 7
---

Taking before-and-after shots, or following a progress bar? **Repeat last region** in the tray menu captures the same area you dragged last time, on the same monitor, as the screen looks now. No overlay, nothing to drag: it's captured the moment you click.

- It remembers the last region you **captured** by dragging, in Region or [All-in-one](/grab-it/capture/all-in-one/). Text captures and colour picks don't change it.
- It remembers it until you quit Grab-it.
- If you haven't captured a region yet, Grab-it says *"Capture a region first, then this captures the same area again."*
- If the monitor it was on has since been unplugged, Grab-it says so instead of guessing.

All-in-one starts with the last region already selected on its monitor, so you can also adjust it a little before capturing again.

:::note
Repeat last region isn't available on Wayland, since the desktop always asks you to pick the area there. See [Wayland](/grab-it/capture/wayland/).
:::
